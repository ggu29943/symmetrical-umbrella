# 《闪电》科普短片 · 分镜脚本 v2（定稿）

v1 之后按你的反馈做了三处修改：
- 不要配音，只配乐。
- 不用传统字幕条，中文文字直接排在画面里，可以带透视、跟随物体、带引线。
- 只保留中文，不再有英文。
- 唯一的例外：闪电类型名统一写成「中文 + 英文」（如「绿色幽灵 GHOST」「淘气精灵 ELVES」），英文小一号、换成该类型的浅色，作为名称的一部分和中文一起入场、一起退场。全片 17 个类型名都按这个格式。

- 规格：1920×1080，16:9，60 fps，3:06（11,160 帧；补入"巨型喷流"和"绿色幽灵 GHOST"后由 3:00 延长 6 秒）
- 配乐：全部由代码合成，每一道闪电的冲击声都按画面帧对齐。远处的热闪电和数秒演示中的闪光故意不发声，与科学内容一致。
- 文字原则：
  - 每段文字都有完整的入场和退场动画（逐字模糊聚焦、上浮、霓虹式闪亮点亮、扩散、盖章等）。
  - 文字退场结束后，下一段才入场。全片每 0.2 秒做一次自动检测，文字之间零重叠。
  - 凡是"尚无定论 / 仍在研究"，统一用琥珀色细框标记，形成贯穿全片的视觉符号。
